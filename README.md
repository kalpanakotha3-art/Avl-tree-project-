# 🌳 AVL Tree Visualizer

An interactive web-based visualization tool for AVL Trees - a self-balancing Binary Search Tree.

🔗 **Live Demo:** [Click here to view](https://your-username.github.io/Avl-Tree-Visualizer/)

### ✨ Features
- Insert nodes with automatic balancing
- Delete nodes
- Search operation
- Real-time visual rotation (LL, RR, LR, RL)
- Clean and interactive UI

### 🛠️ Tech Stack
- HTML, CSS, JavaScript
- Canvas / DOM for tree visualization

### 🚀 How to Use
1. Enter a number and click Insert
2. Watch the tree balance itself automatically
3. Try Delete and Search

### 📂 File Structure
- `index.html` - Main visualizer code
